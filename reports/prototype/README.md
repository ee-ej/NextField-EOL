# V1 Prototype Tables

Generated: 2026-09-03
Source: V1 workbook only

These CSVs are local, reviewable prototype projections generated by `projects/build_v1_prototype_tables.py`. The source workbook is read-only and is not modified.

Run `py -3 projects\validate_v1_prototype.py` after generation to verify keys, relationships, restored SLC05, test-record handling, controls, and exception counts. The generated SPOF composite key and exception-key checks are also part of the current validation pass.

- `fact_spof_observation.csv`: 4,092 normalized site/question observations with answer-state status.

- `V1_IMPLEMENTATION_HANDOFF.md`: completed validation, local implementation package, remaining work, and publication gates.
- `V1_REPORT_BUILD_CHECKLIST.md`: page-by-page local authoring checklist and acceptance tests.

## Current limitations

- Site-risk facts are projected from the validated output artifact; SLC05 remains absent from the source risk output and is represented as missing, not zero.
- SLC05 site-level attributes, SPOF responses, and site-risk output remain unavailable in V1 and are represented as missing, not zero.
- Test asset 7057 remains in the physical prototype table for traceability but must be excluded from governed measures.
- The 3,351 incomplete score rows remain visible through validation status and require further classification.
